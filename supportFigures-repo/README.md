# supportFigures-repo

Figures that belong with the book but are not printed in it. Each is produced
by a script in `supportScripts-repo/`, which writes it here.

| Figure | Produced by | Referred to in |
|---|---|---|
| `conv1_filters_colour.png` | `make_filter_figure.py` | Appendix D: all 64 first-layer filters of AlexNet in colour; the book prints only the 44 that vary mostly in brightness, because colour-opponent filters cannot be reproduced with its four inks |
