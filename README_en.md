# A (not-so-for-dummies) Introduction to Generative and Agentic AI — companion

*[Versione italiana](README_it.md)*

This repository is the companion to the book. The book is a single argument,
read straight through; what a printed page cannot carry lives here.

**Nothing has been published yet.** The repository is being prepared, and this
note is a placeholder, so that the address printed in the book resolves to
something rather than to an empty page.

## What will be here

- **Exercises and solutions** — ten for each of the book's technical chapters,
  from Autoencoders to Agentic AI. They are not printed in the book on purpose:
  a printed exercise is answered once and read as a worked example ever after,
  because the solution is a few pages away and the eye has already been there.

- **Computations in full** — the arithmetic the book states a result for rather
  than spreading over three pages, such as the exhaustive scan behind the claim
  about how far positional similarity decays.

- **Code** — implementations of the models the book derives, written to be read
  next to the chapter that derives them rather than to be efficient; and the
  scripts behind the figures that came from a model actually trained: the
  manifold of Chapter 4, the mode collapse of Chapter 5, the corrupted digits
  of Chapter 6. Seeded, so that a sceptical reader can regenerate them.

- **Corrections and updates.** The material on language models and on agents
  has the shorter half-life, and what a printed book cannot revise, a
  repository can.

## What is published here

Compiled PDFs, and code. The LaTeX sources of the book and of this companion
are not part of this repository.
